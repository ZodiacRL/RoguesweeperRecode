# XP / Frutiger Aero Website

A simple static website with a Windows XP / Frutiger Aero inspired design.

## Folder structure

```text
xp-frutiger-site/
├── index.html
└── images/
    ├── logo.png
    ├── example1.png
    ├── example2.png
    └── example3.png
```

## Adding content

Open `index.html` and find the `ADD / REMOVE ITEMS HERE` section.

Copy an `<article class="item">...</article>` block to add another item.

Put your images in the `images` folder and change the image filename in the HTML.

GitHub Pages can host this directly because it is a static HTML/CSS site.
